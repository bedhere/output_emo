# 😊 情绪颜文字输入法 - 使用说明

## 📖 简介

情绪颜文字输入法是一款智能的全局键盘监听工具，能够实时感知你的情绪状态，并自动推荐对应的颜文字表情。无论你在使用微信、QQ、浏览器还是任何应用程序，只需输入情绪相关的词汇，就能获得最合适的颜文字推荐！

---

## 🚀 快速开始

### 1. 启动程序
- 运行 `output_emo.jar` 或在IDE中运行 `Main.java`
- 程序启动后会自动最小化到系统托盘
- 双击托盘图标即可打开主窗口

### 2. 基本使用
- **全局监听**：程序会自动监听你在任何地方的键盘输入
- **情绪识别**：当你输入情绪相关词汇时，程序会自动弹出并推荐颜文字
- **选择颜文字**：点击三个推荐的颜文字按钮，即可复制到剪贴板

## ⌨️ 快捷键指南

### 全局快捷键
- **Ctrl + Shift + E**：快速呼出程序窗口（全局监听失败时的备用方案）

### 窗口内快捷键
- **数字键 1/2/3**：快速选择对应的颜文字并复制
- **Enter键**：清除当前输入，重置状态
- **ESC键**：隐藏窗口

### 鼠标操作
- **点击颜文字按钮**：复制颜文字到剪贴板
- **点击 ✕ 按钮**：清除输入框内容
- **拖拽标题栏**：移动窗口位置
- **双击托盘图标**：显示/隐藏窗口

## ⚙️ 技术架构

### 核心组件
- **WindowsGlobalKeyboardListener**：Windows底层键盘钩子，实现全局监听
- **EmotionService**：情绪识别引擎，支持多种情绪关键词匹配
- **EmojiRepository**：颜文字数据库，包含100+精选颜文字
- **AppUI**：现代化图形界面，支持动画和交互

### 技术栈
- **Java 11+**：运行环境
- **JNA (Java Native Access)**：访问Windows系统API
- **Swing**：图形界面框架
- **Windows Low-Level Keyboard Hook**：全局键盘监听技术

## ❓ 常见问题

### Q1: 为什么在某些应用中无法监听键盘？
**A**: 某些特殊应用（如游戏、虚拟机）可能会拦截全局键盘钩子。这是Windows系统的正常行为。

### Q2: 如何退出程序？
**A**: 
- 方法1：点击窗口右上角的 ✕ 按钮
- 方法2：右键点击系统托盘图标，选择"退出"

### Q3: 颜文字可以自定义吗？
**A**: 可以！编辑 `EmojiRepository.java` 文件，在对应情绪类别中添加新的颜文字即可。

### Q4: 如何添加新的情绪类型？
**A**: 
1. 在 `EmotionService.java` 中添加新的情绪识别逻辑
2. 在 `EmojiRepository.java` 中添加对应的颜文字列表
3. 在 `AppUI.java` 的 `updateEmotionLabel` 方法中添加新的情绪标签样式

### Q5: 程序会收集我的输入内容吗？
**A**: 不会！程序完全在本地运行，所有输入仅用于实时情绪识别，不会上传到任何服务器。
