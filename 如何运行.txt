========================================
  情绪颜文字输入法 - 运行指南
========================================

环境要求：
- Windows 操作系统
- Java 11 或更高版本
- Maven 3.6 或更高版本

----------------------------------------
方法 1：使用运行脚本（推荐，最简单）
----------------------------------------
1. 双击 run.bat 文件
2. 脚本会自动检查环境并启动应用

如果脚本无法运行，请尝试方法 2。


----------------------------------------
方法 2：使用 Maven 命令
----------------------------------------
1. 打开命令提示符或 PowerShell
2. 进入项目目录：cd D:\javacode\output_emo1
3. 执行命令：mvn clean javafx:run


----------------------------------------
方法 3：使用 IDEA 运行
----------------------------------------
1. 用 IDEA 打开项目
2. 打开右侧 Maven 工具窗口
3. 展开 output_emo > Plugins > javafx
4. 双击 javafx:run 即可运行

或者：
1. 点击 IDEA 右上角的 "Add Configuration..."
2. 点击 "+" 添加 "Application" 配置
3. 填写以下信息：
   - Name: Main
   - Main class: com.emotionime.Main
4. 点击 Apply 和 OK
5. 现在可以直接点击运行按钮运行


----------------------------------------
方法 4：打包后运行 JAR
----------------------------------------
1. 执行打包：mvn clean package
2. 运行：java -jar target\output_emo.jar


========================================
使用说明
========================================

1. 启动后在屏幕右下角显示输入法窗口
2. 在任意应用中输入文字，输入法会自动检测情绪
3. 点击颜文字按钮或按数字键 1/2/3 选择颜文字
4. 选中的颜文字会自动复制到剪贴板

快捷键：
- 1/2/3：选择对应位置的颜文字
- Enter：清除输入框
- Esc：隐藏窗口
- Ctrl+E：全局清除输入

界面按钮：
- "清"：清除输入框
- "钩"：切换全局监听开关
- "—": 最小化到托盘
- "✕"：关闭程序


========================================
常见问题
========================================

Q: 提示 "未找到 Java" 怎么办？
A: 需要安装 Java 11 或更高版本，推荐使用 Eclipse Temurin：
   https://adoptium.net/

Q: 提示 "未找到 Maven" 怎么办？
A: 需要安装 Maven，下载地址：
   https://maven.apache.org/download.cgi

Q: 全局键盘监听不工作怎么办？
A: 尝试以管理员身份运行，或检查是否有杀毒软件拦截

Q: 颜文字显示为方块怎么办？
A: 确保系统安装了支持 Emoji 的字体（Windows 10/11 自带）
